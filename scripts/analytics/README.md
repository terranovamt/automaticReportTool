# ART.stdf Analytics Scripts

Utility scripts for analyzing ART.stdf usage and performance.

## Scripts

### usage_analytics.py

Generates usage statistics and analytics for the STDF processing system.

**Usage:**
```bash
python scripts/analytics/usage_analytics.py [options]
```

**Features:**
- Processing statistics
- Performance metrics
- Usage trends
- Report generation analytics
